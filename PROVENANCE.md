## Mixed, and how to read them

- **Model names**: each summary names the model that actually ran. The current configuration is claude-sonnet-5-5 for the draft and claude-haiku-5-5 for the cleanup pass; earlier single runs were on claude-fable-5-1. In production, the bank would pin (fix) a model version behind the bank's gateway, its controlled access point to the model.
- **Memo view and the saved memos**: the memo editor, comments and Word export were built by Claude Code on 2026-10-07. The saved memos hold real machine-section drafts from Sonnet 5.5 with Haiku 5.5 cleanup; their underwriter sections (7 to 10) are empty, as intended.
- **Known inconsistency, kept on purpose (decided 2026-10-08):** D1 Table 3's pro forma debt service of 5,600 does not reconcile with the seven-year amortization in D2 §2.1(a). The figure comes from the specification's ledger. The tool is expected to flag it as a number with no stated basis that the underwriter must rebuild.
